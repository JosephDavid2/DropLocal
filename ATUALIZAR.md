# Atualizar Drop Local

Versão 0.8.2 — by Joseph David.

Baixe o MSI Windows e o APK Android da [release](https://github.com/JosephDavid2/DropLocal/releases/latest). No Windows, abra DropLocal-Setup.msi. O Windows Installer cuida da atualização; feche transferências em andamento antes de instalar. No Android, instale o APK sobre a versão anterior; a assinatura foi preservada. Atualize ambos para usar o fluxo automático.

Para remover no Windows, use Configurações > Aplicativos > Drop Local > Desinstalar ou o atalho Desinstalar Drop Local no menu Iniciar. Ambos usam o Windows Installer. Arquivos pessoais e recebidos são preservados.

Não use o protótipo 0.8.1 nem seu antigo alias EXE. O pacote atual é MSI. Consulte [validação](VALIDACAO-0.8.2.md) e [guia](USAR-0.8.2.md).
