# Drop Local 0.8.3 — by Joseph David

Abra o Drop Local nos dois aparelhos, na mesma rede. No Windows, arraste arquivos para o destinatário ou clique nele. No Android, toque no aparelho e escolha os arquivos. Quem recebe confirma o pedido.

Windows recebe em Downloads/DropLocal; altere a pasta em Configurações. No Android, escolha uma pasta para receber uma vez. Mantenha o aplicativo aberto durante as transferências.

O botão Atualizar consulta as releases estáveis de JosephDavid2/DropLocal no GitHub. Se houver versão mais nova, confirma o download, verifica o SHA-256 e abre o instalador nativo. Não é necessário desinstalar. No Android, volte ao app após o download e autorize a instalação quando o sistema solicitar. Consulte ATUALIZAR.md no repositório para publicação e detalhes.

No Android, o destinatário fica preservado durante a seleção de arquivos, mesmo quando anúncios de descoberta expiram. Se o computador mudar de endereço e reaparecer com o mesmo id, os dados da operação são atualizados. O envio ainda exige conexão e aceitação do receptor. Encerramento do processo durante a seleção não é coberto.

Limites: Android 8 ou superior, Windows x64, mesma rede sem isolamento de clientes, até mil arquivos por lote, sem retomada de transferência interrompida. A transferência local não usa TLS; use uma rede de confiança. A consulta de atualizações usa HTTPS e internet.

Para atualizar de 0.8.2, instale a primeira versão com o botão sobre a atual, sem desinstalar. Para remover no Windows, use Configurações > Aplicativos ou o atalho Desinstalar Drop Local no menu Iniciar.
